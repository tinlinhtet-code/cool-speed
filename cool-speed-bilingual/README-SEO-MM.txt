SEO CHECKLIST AFTER DOMAIN IS KNOWN:
1. Replace the root-relative hreflang URLs in BOTH HTML files with absolute URLs, e.g.
   <link rel="alternate" hreflang="en" href="https://YOURDOMAIN.com/">
   <link rel="alternate" hreflang="my" href="https://YOURDOMAIN.com/mm/">
   <link rel="alternate" hreflang="x-default" href="https://YOURDOMAIN.com/">
2. Add canonical tags with absolute URLs to each page:
   EN: <link rel="canonical" href="https://YOURDOMAIN.com/">
   MM: <link rel="canonical" href="https://YOURDOMAIN.com/mm/">

3. Add both URLs to sitemap.xml and submit sitemap in Google Search Console.
4. Confirm hosting serves /mm/ as mm/index.html and SSL/HTTPS works.
5. Check that robots.txt does not block either page and both are indexable.
